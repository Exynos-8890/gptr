# Experiment: R execution with a tool-call hook

Base: `5e2992b13824fbf5218428d379a336dd44acddbb`.

Both direct and MCP-served R calls bypass outer input validation, risk classification, permission
gating and checkpoints. They retain the `tool_call` hook, with `risk = NULL`, and the start/end
events previously reported by each route. Direct R calls skip `tool_result` hooks. Other tools keep
their existing gate. R's evaluator and nested-tool guards still apply.
The built-in background change notice uses a `tool_result` hook, so direct R calls no longer
trigger that notice while this experiment is active.

This is an experiment, not a passing replacement for the existing contract: R calls can
write in plan mode, ignore deny rules and leave changes that rewind does not restore. The bypass
also skips MCP checks for a blocked run and conversation compaction. Some previously allowed
nested operations can instead fail because the skipped gate no longer issues their one-shot
control grants; an existing `gptr_register()` test demonstrates this.

## Previous offline benchmark

These results measured the previous MCP-only experiment (`bd5a8234`), which did not run the
`tool_call` hook. They do not measure the amended direct or MCP implementation. T03 A1-2 used the
offline provider and the same 1,231 manifest-verified public input files, three runs per version.
The measurement excludes live model, network and CLI transport time. The third pair reversed order.

| Request | Baseline median | Experiment median | Reduction |
| --- | ---: | ---: | ---: |
| 1 | 56.038 s | 40.483 s | 27.8% |
| 2 | 19.512 s | 2.394 s | 87.7% |
| 3 | 19.031 s | 1.806 s | 90.5% |

All six runs generated byte-identical `input-audit.csv`, `sample-summary.csv`, `gene-summary.csv`
and `research-report.md`. The tables also matched the independent T03 reference: one audit row,
1,231 sample rows and 60,660 gene rows. Raw inputs, replay logs and timing details are local and
ignored under `tmp/r-execution-only/`.

A separate instrumented baseline replay split request 2's permission processing. The first
`risk_classify_r()` call took 7.734 s before the gate; `tool_call_hook()` took 0.138 s. The gate
called `risk_classify_r()` again for 7.532 s. These timings are from one diagnostic replay, not
additional independent samples, and the classifier's internal work was not split further.

## Verification

- The targeted experiment, evaluator and architecture tests passed 519 expectations. They cover
  direct and served R, hook block and modify, retained events, permission bypass, rewind and non-R
  permissions.
- A broader background test was interrupted after 17 failures and 152 passes; the individual
  failures were not diagnosed.
- The previous MCP-only version failed 56 expectations/errors in the existing `mcp-server` suite
  and two rewind expectations in `cli-codex`. Those counts do not describe this amended version.
- The complete existing CI suite has not been rerun for this amendment, at the user's request.
